Repo is private/mentor-access-only, which permits this kind of working corpus; sources are still listed here for attribution and so the corpus can be re-verified or expanded against the originals.

## Access notes / known gaps

- The full AASLD 2018 PBC Practice Guidance PDF (aasld.org/sites/default/files/.../PracticeGuidelines-PBC-November2018_1.pdf) and the EASL Journal of Hepatology PBC guideline returned 402/403 (paywalled/blocked) via direct fetch — worked around using the open-access APASL PMC summary instead (`01_pbc_diagnosis_udca_response.md`), which covers the same diagnostic/UDCA-response content. The same bot-blocking pattern recurred for the AASLD 2014 HE guideline PDF, the AASLD 2023 portal-hypertension/varices guidance PDF, the HRSA/OPTN MELD calculator page, and NCBI Bookshelf/StatPearls (reCAPTCHA-gated) — each was worked around with an open-access PMC article or an institutional patient-education page (Cleveland Clinic, UPMC, MSKCC-tier) covering the same clinical content, consistent with the file-01 precedent. If deeper AASLD/EASL primary-source detail is wanted later, try these PDFs via an authenticated browser session rather than WebFetch.
- **RESOLVED — KZ/RU PBC-specific protocol found**: Kazakhstan MoH clinical protocol "Первичный билиарный холангит, первичный склерозирующий холангит," Protocol No. 35, approved 14 December 2017 by the Joint Commission for Quality of Medical Services, MoH RK (https://diseases.medelement.com/disease/первичный-билиарный-холангит-первичный-склерозирующий-холангит/15632). This is a PBC-specific protocol (distinct from the general cirrhosis protocol in `02_kz_protocol_cirrhosis.md`) and includes PBC diagnostic criteria, UDCA/second-line dosing tables, a pruritus management ladder, and a monitoring schedule (including DEXA every 2 years) — all with real KZ-context dosing figures, now incorporated into files 09, 10, and 13. No further KZ/RU PBC-specific source search needed.
- The corpus now has 13 files (01-13) against the plan's 15-25 doc target — comfortably past the lower bound given the project's tight timeline; further additions (e.g. a dedicated autoimmune-overlap-syndrome page, or a vaccination/infection-prevention-in-cirrhosis page) would be nice-to-have, not required, for submission.
- No native Kazakh-language clinical source was found at usable scale (consistent with the plan's documented bilingual-corpus trade-off) — all KZ-sourced protocols in this corpus are Russian-language.
